# 집값레이더 — 아파트 평형별 적정가 분석

서울/경기 아파트 단지를 검색하면 국토교통부 공공데이터(실거래가, 전월세, 단지 기본정보,
건축물대장)를 기반으로 평형별 적정가격을 추정해서 보여주는 웹앱입니다.

## 주요 기능

- 평형별 추정 적정가(최근 3년 실거래가 가중회귀), 직전거래가, 전고점 돌파 여부
- 전세가율(최근 1년 전월세 실거래 기반)
- 단지 기본정보(세대수/동수/준공연도/건폐율/용적률/총 주차대수) 자동 조회
- 지도(무료 OpenStreetMap, 지오코딩)
- 매물 호가를 직접 입력하면 적정가 대비 급매/협상여지 자동 판단
- 매수 비용 계산기(중개수수료 상한액 + 취득세)
- 검색 시 후보 단지 확인 절차(다른 단지와 오매칭 방지)

## 왜 네이버 부동산 매물/호가가 자동으로 안 나오나요?

네이버 부동산은 공식 공개 API가 없고, 실시간 매물/호가를 가져오려면 비공식 방식으로
스크래핑해야 합니다. 이 프로젝트가 개발된 환경에서는 네이버 부동산 도메인 접근이
정책적으로 차단되어 있어 자동화하지 않았습니다. 대신 단지/평형별로 "매물 개수·호가"를
직접 입력해두는 칸을 제공합니다 — 네이버 부동산에서 확인한 값을 입력하면 저장되어
다음에 조회할 때도 함께 보이고, 추정 적정가와 자동으로 비교됩니다.

## 1. 공공데이터포털 API 키 발급 (직접 진행 필요)

1. https://www.data.go.kr 회원가입 및 로그인
2. 아래 API들을 각각 검색해서 **활용신청** (전부 자동승인이라 바로 사용 가능)
   - `국토교통부_아파트매매 실거래자료` (RTMSDataSvcAptTrade)
   - `국토교통부_아파트 전월세 실거래자료` (RTMSDataSvcAptRent) — 전세가율용
   - `국토교통부_공동주택 단지 목록제공 서비스` (AptListService4)
   - `국토교통부_공동주택 기본 정보제공 서비스` (AptBasisInfoServiceV5) — 세대수/동수 등
   - `국토교통부_건축HUB_건축물대장정보 서비스` (BldRgstHubService) — 건폐율/용적률
3. 마이페이지 > 개발계정에서 발급받은 **일반 인증키(Encoding/Decoding 아무거나)** 복사
   — 모든 API가 같은 키를 공유하지만, 각 API를 개별적으로 활용신청해야 합니다.
4. `.env.example`을 복사해 `.env`로 만들고 `MOLIT_SERVICE_KEY=` 뒤에 붙여넣기

```bash
cp .env.example .env
```

## 2. 로컬 설치 및 실행

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
cd backend
uvicorn main:app --reload --port 8000
```

브라우저에서 http://localhost:8000 접속. (이 방법은 본인 컴퓨터에서만 접속되며,
다른 사람에게 링크로 공유할 수는 없습니다 — 공유하려면 아래 "배포하기" 참고.)

## 3. 배포하기 (다른 사람과 링크 공유)

[Render](https://render.com) 무료 티어 기준 안내입니다. 저장소 루트에 있는
`render.yaml`을 그대로 사용합니다.

1. 이 폴더를 GitHub 저장소로 푸시 (아래 "Git 준비" 참고)
2. Render 대시보드 → **New +** → **Blueprint** → 방금 만든 GitHub 저장소 선택
   → `render.yaml`을 자동으로 인식합니다
3. 배포 전 환경변수 입력 화면에서 `MOLIT_SERVICE_KEY`에 위에서 발급받은 키를 붙여넣기
   (`.env` 파일은 `.gitignore`로 제외되어 저장소에 올라가지 않으므로, 여기서 다시
   입력해야 합니다)
4. 배포가 끝나면 Render가 주는 `https://xxxx.onrender.com` 형태의 URL을 공유

### Git 준비 (최초 1회)

```bash
git init
git add .
git commit -m "Initial commit"
```

이후 GitHub에서 새 저장소를 만들고, 안내되는 `git remote add origin ...` 및
`git push` 명령을 그대로 실행하면 됩니다.

### 배포 시 참고사항

- 무료 티어는 일정 시간 요청이 없으면 서버가 잠들었다가, 다음 요청 때 다시 깨어나는
  데 시간이 걸릴 수 있습니다(첫 요청이 느릴 수 있음).
- SQLite 캐시 파일은 재배포/재시작 시 초기화됩니다(디스크가 영구적이지 않음) —
  캐시가 없어도 다시 조회하면 API를 새로 호출해 채워지므로 기능상 문제는 없습니다.
- 국토교통부 API 개발계정은 하루 호출 한도가 있습니다(대략 API당 5,000건). 테스트
  인원이 많아지면 한도에 걸릴 수 있으니, 필요하면 data.go.kr에서 운영계정으로
  전환 신청하세요.
- Nominatim(지도 좌표 변환)은 무료 서비스 이용정책상 과도한 트래픽을 보내면 안
  됩니다 — 개인/소규모 테스트 용도로는 문제없습니다.

## 4. 사용법

- "시군구" 칸에는 서울/경기 시군구만 지원합니다 (예: 강남구, 분당구, 수원 영통구).
- 검색하면 이름이 비슷한 단지 후보를 먼저 보여줍니다 — 주소를 확인하고 맞는 단지를
  선택해야 실거래가 조회가 시작됩니다(다른 단지와 오매칭 방지).
- 평형은 전용면적을 자동으로 클러스터링해서 구분합니다(같은 단지 내 ±3㎡ 이내는
  같은 평형으로 묶음). 실제 평형 구분과 다를 수 있습니다.

## 적정가 추정 방법

- 최근 3년 실거래가에 최근 거래일수록 더 큰 가중치(반감기 180일)를 주는 가중회귀직선을
  적합해 오늘 시점 추세가를 추정합니다. 표본이 3건 미만이면 가중평균으로 대체합니다.
- 직전거래가, 전고점(최근 3년 내 최고가) 대비 현황, 최근 가격대(25~75 백분위수)도
  함께 제공합니다.
- **투자 자문이 아닌 통계적 참고용 추정치입니다.**

## 한계

- 실거래가 API의 `아파트명` 문자열 매칭에 의존하므로, 이름이 비슷한 다른 단지와
  오매칭될 위험이 있습니다 — 검색 시 후보 확인 절차로 이를 보완합니다.
- 건폐율/용적률/총 주차대수는 건축물대장(총괄표제부) 데이터에 실제로 등록이 안 되어
  있는 경우(특히 오래된 단지)가 있어, 이때는 "직접입력 필요"로 표시됩니다.
- 매물 개수·호가는 자동 조회하지 않고 수동 입력만 지원합니다(정책상 네이버 부동산
  자동화 불가).
- 현재 서울/경기만 지원합니다(`backend/data/legal_dong_codes.csv`에 시군구 코드를
  추가하면 다른 지역도 확장 가능).
